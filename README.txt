บัญชีรายรับ INCOME 5

วิธีใช้งาน:
1) ทดลองเปิด index.html ใน Chrome หรืออัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปยัง GitHub Pages
2) เปิด URL ผ่าน Chrome บน Android แล้วเลือกเมนู เพิ่มไปยังหน้าจอหลัก / ติดตั้งแอป
3) ข้อมูลเก็บในเบราว์เซอร์ของเครื่องที่ใช้งาน ควรดาวน์โหลดไฟล์สำรอง JSON เป็นประจำ
4) เมื่อต้องการย้ายเครื่อง ให้ดาวน์โหลดไฟล์สำรองจากเครื่องเดิม แล้วเลือกไฟล์นั้นในเมนู สำรอง เพื่อกู้คืน

หมายเหตุ: ระบบต้องใช้เครือข่ายในการโหลดครั้งแรก; การทำงานออฟไลน์รองรับหลัง service worker ติดตั้งสำเร็จผ่าน HTTPS
